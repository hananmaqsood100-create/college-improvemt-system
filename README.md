# 🎓 Campus Feedback System

**A full-stack web application for managing student feedback across campus facilities.**

Built with Flask + MySQL for transparent communication between students and administration.

### 🚀 Key Features
- **Multi-Role Access**: Separate dashboards for Students & Admins
- **Category-wise Feedback**: Classroom, Hostel, Library, Canteen, Washrooms
- **Real-time Tracking**: Check complaint status: Pending → In Progress → Resolved
- **Admin Panel**: Manage feedback, update status, resolve issues
- **Secure Authentication**: Session-based login for students and admin

### 🛠️ Tech Stack
**Backend**: Python, Flask  
**Database**: MySQL  
**Frontend**: HTML5, CSS3, JavaScript  
**Security**: Session Management, Password Hashing

### 🔧 Setup Instructions
1. Clone: `git clone https://github.com/hananmaqsood100-create/college-improvemt-system.git`
2. Install: `pip install flask mysql-connector-python`
3. Setup DB: Import `database.sql` into MySQL
4. Run: `python app.py`
5. Visit: `http://localhost:5000`
